# Calculadora Ancestral
Uma simples calculadora, mas feita de modo mais descontraída!
Usada para praticar Lógica de Programção no curso de Análise de Dados pela Ebac

A Calculadora detém das quatro operações básicas de adição, subtração, divisão e multiplicação, todas sendo apresentadas de maneira divertida
e descontraída.

Para executar o arquivo:

1º Abra o Ubuntu/Shell Script

2º Encontre a pasta a pasta do arquivo executável

3º Se necessário, dê permissão de execução utilizando "chmod 744 mega_calculadora.sh"

4º Por fim, execute o arquivo "./mega_calculadora.sh"
